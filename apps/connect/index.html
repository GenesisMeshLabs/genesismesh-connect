UNDERSTAND PERMISSIONS
Who can access what?
Being on the same network is the first step. Each shared item has its own rules.

            
    
              
  1. Joining identifies a deviceYour network owner approves the device. Review known devices from Devices.
    2. 
              
  2. Sharing gives access to an itemOn the device that shared it, open Shared → Manage → Manage access. Choose allowed devices, an expiry and limits. Additional rules are available there.
    3. 
              
  3. Each request checks the current rulesYour authority evaluates access. An expired or revoked identity, a policy limit, or an unavailable network computer can stop a request.
    4. 
            

            

            
Reading, sending and services
Shared files let chosen devices view or save copies. Receive files chooses who may send copies to this device. App and service sharing opens a connection to a service already running on its host. Each uses its own permission.
If someone else shared the item, ask that device’s owner to update its access. A connection check confirms a connection; the next file or service request evaluates its own policy.

            
Inspect this device’s identity and trust
Certificate expiry, the pinned network root and verified trust checkpoints are available for a detailed diagnosis.
